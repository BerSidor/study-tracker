# Week 4 — Day-by-Day: AI/ML for Builders + Software Architecture

> **Week goal:** the conceptual grounding to build *robust* AI systems — and stand up your
> freelance presence (Phase C begins this week, in parallel).
> **Ship by Saturday:** a small RAG-backed tool + design-patterns→AI notes; freelance profile live.
> **Study days:** Mon–Sat (Sunday rest). ~6.7 h/day. Log every block with the tracker.

This week connects your ML background and your design-patterns goal to *building* with Claude.
Saturday flips on the freelance engine that runs through Week 7.

---

## Day 1 (Mon) — Prompt Engineering `~6h`
**Tracker:** `start "Prompt engineering"`

- **Learn (3h):** structuring prompts, system vs user roles, few-shot, decomposition, and how
  prompt design changes tool-use reliability.
- **Practice (3h):** take a flaky prompt and iterate it to reliable; document what moved the needle.

## Day 2 (Tue) — RAG Systems `~7h`
**Tracker:** `start "RAG systems"`

- **Learn (3h):** retrieval-augmented generation — chunking, embeddings, vector search, when RAG
  beats long context.
- **Build (4h):** start a small RAG tool over a corpus you have (your study notes / `MCP Servers/`).

## Day 3 (Wed) — Agent Architectures + Design Patterns `~7h`
**Tracker:** `start "Agent architectures"` → `start "AI system design patterns"`

- **Learn (4h):** common agent architectures (tool-use loop, planner-executor, reflection,
  multi-agent). Map them to classic design patterns (strategy, observer, pipeline) — *internalize
  patterns by seeing where they live in AI systems* (your stated goal).
- **Practice (3h):** diagram the architecture of one system you've built or want to build.

## Day 4 (Thu) — Anthropic API & Cost Economics `~6h`
**Tracker:** `start "Anthropic API & cost economics"`

- **Learn (4h):** the API directly — tool use, prompt caching, streaming, token counting. Model
  tiers and pricing. **Token economics = your future startup's gross margin** — learn to estimate
  cost-per-task.
- **Practice (2h):** instrument one of your tools to log token usage and estimate per-call cost.

## Day 5 (Fri) — LLM Evaluation + Finish RAG Tool `~7h`
**Tracker:** `start "LLM evaluation basics"` → `start "RAG tool"`

- **Learn (3h):** how to evaluate LLM output — golden sets, LLM-as-judge, regression checks.
- **Build (4h):** finish + lightly evaluate your RAG tool. Ship it.

## Day 6 (Sat) — Freelance Setup `~6h`
**Tracker:** `start "Freelance setup"`

- **Build:** stand up a freelance presence. Profile + portfolio using Weeks 1–3 artifacts
  (published MCP server, slash command, multi-agent workflow). Pick 1–2 channels to hunt:
  Upwork/Contra, indie/AI communities, local businesses, university network.
- **Discovery Log:** note the kinds of gigs being posted — early market signal.
- **Run `report`.**
