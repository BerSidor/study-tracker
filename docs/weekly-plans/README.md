# Weekly Plans — Day-by-Day

Day-by-day breakdowns of the 8-week summer plan. See `../startup-study-plan.md` for the
high-level arc and `../../data/discovery-log.md` for the niche-hunt journal.

Each week: Mon–Sat, ~6.7 h/day, ends with a shipped artifact and a Definition of Done.

| Week | Focus | Ship target |
|---|---|---|
| [Week 1](week1-daily.md) | Claude Code Core & Configuration | Fresh project + tailored `CLAUDE.md` + custom hook |
| [Week 2](week2-daily.md) | MCP Servers Deep Dive | Published MCP server (**portfolio #1**) |
| [Week 3](week3-daily.md) | Agents, Subagents, Skills & Plugins | Slash command + multi-agent workflow (**portfolio #2**) |
| [Week 4](week4-daily.md) | AI/ML for Builders + Architecture | RAG tool + freelance profile live |
| [Week 5](week5-daily.md) | End-to-End Product Build | Deployed AI web app (**portfolio #3**) + first gig |
| [Week 6](week6-daily.md) | Market & Competitor Analysis | Candidate-niche shortlist |
| [Week 7](week7-daily.md) | Validation | One committed thesis + MVP scope draft |
| [Week 8](week8-daily.md) | Startup Thesis + Fall Plan | Thesis one-pager + MVP scope + Fall roadmap |

**Phases:** A = master the tool (Wks 1–3) · B = builder foundations (Wks 4–5) ·
C = earn & discover (Wks 4–7, parallel) · D = synthesize the niche (Wks 6–8).

**Non-negotiables if time slips:** (1) published MCP server, (2) deployed end-to-end app,
(3) Discovery Log → validated thesis.
